01

Маркетинг — сквозная аналитика Рабочий инструмент · Google Apps Script

Рабочий дашборд на Google Apps Script (Web App), данные тянутся из CRM и Meta Ads. Путь «реклама → лид → квалификация → продажа → оплата»; CPL / CAC / ROMI / ROAS, окупаемость по кампаниям и креативам, источники UTM. Результат: отключены неэффективные креативы, доля квалифицированных лидов выросла до 40%, CPL и CAC снизились на ~25%.

02

Отдел продаж — РНП Рабочий инструмент · Google Apps Script

Рабочий дашборд на Google Apps Script (Web App). Воронка состояний лида по каждому менеджеру, план-факт, конверсии между этапами, сравнение менеджеров и динамика по дням. Подсвечивает узкие места воронки и даёт основания для управленческих решений.

03

Обзор бизнеса — единый дашборд

Лиды, продажи, CPL, окупаемость, воронка и каналы рекламы в одном окне. Руководство видит состояние бизнеса в реальном времени вместо ручных Excel-сводок.

04

Финансы — P&L и план-факт

Управленческий P&L, выполнение плана месяца, структура расходов. Собирается автоматически из CRM и рекламных кабинетов — без ручного сведения.

05

EasyMebel — маркетплейс сборки заказа

Сборка заказа из стандартных модулей → накладная клиенту + смета для цеха (листы ЛДСП, кромка, фурнитура, себестоимость) → выгрузка в Trello. Цель — цикл заказа 3 дня.
